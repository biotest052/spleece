# spleece

Unofficial web client for browsing, previewing, and downloading Splice sounds for free.

## Usage

You will need Node.JS with npm (or any other alternative, like pnpm) installed.
After you installed them, you can run spleece with these commands:

```bash
npm install
npm run dev
```

## Features

- Search samples by query, key, BPM range, category, tags
- Sort by popularity, relevance, newest, or random
- Browse sample packs as cards with artwork
- Click a pack to view all its samples
- Preview samples with waveform visualization
- Download as WAV or original format
- Dark/light theme
